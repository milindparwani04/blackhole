# Blackhole

Local-first personal backlog for **games, movies, TV and books**. Specs: `BLACKHOLE_BRD.md`, `BLACKHOLE_PRD.md`, `BLACKHOLE_THREE_AGENT_CONSOLIDATED_RESEARCH.md`.

## Run

Requires Node 22.13+ (uses the built-in `node:sqlite`; developed on Node 24).

```sh
npm install
npm start            # build UI + serve everything at http://127.0.0.1:4317
npm run serve        # serve the existing build without rebuilding
npm run dev          # hot reload: API on 4317, UI on http://localhost:5173
npm test             # API/integration tests (in-memory DB)
npm run typecheck
```

Your library is stored in `data/blackhole.sqlite`; backups go to `data/backups/`. Both are git-ignored.

Optional `.env` (see `config.example.env`): `PORT`, `DATA_DIR`, `DATABASE_PATH`, `LOG_LEVEL`. The server refuses to bind anything other than loopback (D-01).

## SearXNG (trophy lookup)

```sh
# one-time (already done on this PC)
docker run -d --name blackhole-searxng --restart unless-stopped -p 127.0.0.1:8888:8080 \
  -v "<Blackhole folder>/searxng:/etc/searxng" searxng/searxng:latest
```
`searxng/settings.yml` is generated from `settings.example.yml` with a random `secret_key` (git-ignored).

## Desktop shortcut (Windows)

`Desktop\Blackhole.lnk` → `scripts\launch-blackhole.vbs` (no console window) → `scripts\launch-blackhole.ps1`:
starts Docker Desktop / the SearXNG container if needed, starts the server if it isn't running (logs in `data\logs\`),
then opens Blackhole as an app window (Chrome or Edge `--app`, else the default browser).
The server keeps running after the window closes; stop it with `powershell -File scripts\stop-blackhole.ps1`.
Icon: `assets\blackhole.ico`, regenerated by `scripts\make-icon.ps1`.
